PC Quick Fix Toolkit

Fix common Windows problems in one click. One file, nothing to install, results in plain English.

Download from GitHub View the project

Free and open source. Windows 10 and 11. Version 1.1.

What it fixes

  • Fix my PC automaticallyChecks the basics, fixes the safe problems and tells you what it did.
  • Internet problemsTests your connection, refreshes DNS and offers a deeper network reset.
  • Free up spaceClears temporary files and shows space before and after.
  • Hardware and Windows healthChecks drive health, battery, devices, security and system components. Changes nothing.
  • Printer and Windows UpdateClears stuck print jobs and resets a stuck Windows Update.
  • Health reportSaves a report you can send to your IT person.

How to use it

  1. Download PC-Quick-Fix-Toolkit.cmd from GitHub.
  2. Double-click the file on your Windows PC.
  3. Press 1 and read the summary.

If Windows says it protected your PC, choose More info, then Run anyway, but only if you trust the source.

Is it safe?

It never deletes your personal files, asks before bigger actions, creates a System Restore point before repairs, and logs everything it does. It is a plain text file, so you can read every line before running it.

Using a phone?

A .cmd file only runs on Windows, so it won’t run on Android or iPhone. You can control a Windows PC from your phone with Microsoft Remote Desktop or Chrome Remote Desktop, or read the guide for fixing phone problems.
